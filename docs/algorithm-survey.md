# Algorithm survey and implementation notes

Reviewed November 20, 2026. The crate works with immutable CSR snapshots, integer vertex IDs, parallel edges and original edge IDs. The choice of solver depends on the graph family, the requested certificate, the numeric model, and whether preprocessing can be shared across queries.

## Source provenance

Two locations in the starting Rust source attributed implementation material to NetworkX. The weighted matching module attributed blossom expansion and lifting to its Python implementation. The named-graph module attributed several fixed tables to its numbering. Both have been replaced. The working tree had no Git commits from which to reconstruct the history of unmarked code.

- **Weighted matching.** The new implementation uses original-edge events on a quotient graph. A contracted part stores the cyclic sequence of children and connecting edges. It defers the internal matching until expansion or result extraction. An indexed four-way heap predicts when a crossing edge becomes tight. Exhaustive matching on small multigraphs and an optional external NetworkX process check the objectives. [Edmonds, *Maximum Matching and a Polyhedron with 0,1-Vertices*](https://www.math.u-szeged.hu/~hajnal/courses/MSc_Optimalizalas/2014/Edmonds%20-%20Maximum%20matching%20and%20a%20polyhedron%20with%2001%20vertices%201964.pdf)
- **Named graphs.** The Frucht generator uses Hamiltonian-cycle LCF shifts. Chvátal uses four sectors of the Hamiltonian drawing. Tutte uses three identical 15-vertex fragments and a hub. The house, diamond, bull, kite, and Sedgewick maze use walks through their defining structures. Exact isomorphism checks cover all named fixtures previously compared to Python. Frucht, Chvátal, and Tutte have new vertex numbering. Rebuilt fixtures can also have new insertion-order edge IDs. [Frucht LCF](https://mathworld.wolfram.com/FruchtGraph.html) · [Chvátal construction](https://mathworld.wolfram.com/ChvatalGraph.html) · [Tutte fragment](https://mathworld.wolfram.com/TutteFragment.html) · [Knuth, exercise 27](https://www-cs-faculty.stanford.edu/~knuth/fasc8a.pdf)
- **Distribution.** The Rust library builds and runs independently of Python. NetworkX is used by opt-in test and benchmark drivers through an external installation. The historical notice is retained in the repository under `docs/history` and excluded from the Cargo archive. The default multicommodity feature depends on `microlp` and its Cargo dependencies. Disabling default features builds a standard-library-only crate. Project licensing remains for the owner to specify.

## Flow, matching and spanning forests

| Problem | Implemented choices and guarantees | Research context |
| --- | --- | --- |
| Integral maximum flow | DFS Ford–Fulkerson can require up to F augmentations for value F. Capacity scaling searches residual edges of capacity at least Δ and halves Δ down to one. After a phase, the residual capacity across the reachable cut is less than EΔ, bounding the next phase to O(E) augmentations. Edmonds–Karp, Dinic, Boykov–Kolmogorov, and highest-label push–relabel are also available. All return feasible edge flows and a residual minimum cut. | BFS augmentation is strongly polynomial. Scaling takes O(log(U+1)) thresholds for maximum capacity U. Deterministic almost-linear theoretical flow algorithms use dynamic minimum-ratio cycles, spanners and interior-point optimization. The crate maintains signed cycles in contracted forests with two-hop spanners and optional global ratio certification. Its standalone terminal-cycle solver and barrier variant recover exact integral flows by dyadic Euler rounding. The general subpolynomial update bound and the full interior-point running time remain open here. [Measurements and bounds](../benches/flow.md) [Ford–Fulkerson](https://www.cs.yale.edu/homes/lans/readings/routing/ford-max_flow-1956.pdf) · [Edmonds–Karp](https://web.eecs.umich.edu/~pettie/matching/Edmonds-Karp-network-flow.pdf) · [van den Brand et al.](https://arxiv.org/abs/2309.16629) |
| Costed and concurrent flow | Primal network simplex, cost scaling, cycle canceling and successive shortest paths solve integer cost problems under their documented preconditions. For pure max flow, the simplex wrapper adds a unit reward for each unit returned from the sink to the source. Multiple return arcs accommodate totals above u64. Commodities sharing both terminals use one exact max flow split in proportion to demand. General concurrent fractional flow uses the existing sparse LP with feasibility checks. | Network simplex has exponential pivot sequences. Cost scaling and almost-linear algorithms have different worst-case guarantees. The independent multiplicative-weights path-packing API returns a primal allocation, a shortest-path dual upper bound, and whether its requested relative gap was attained within the round limit. [Goldberg–Tarjan](https://doi.org/10.1287/moor.15.3.430) · [Chen et al.](https://arxiv.org/abs/2203.00671) · [Garg–Könemann](https://doi.org/10.1137/S0097539704446232) |
| Bipartite cardinality | Kuhn searches one alternating path per root. Hopcroft–Karp batches shortest augmentations. The seeded random-walk solver samples a free left root, walks through matched right-to-left pairs, erases loops, and flips the resulting augmenting path. Repeated unsuccessful trials trigger exact Hopcroft–Karp completion. All expose a minimum vertex cover. | Goel–Kapralov–Khanna prove expected O(n log n) on positive-degree regular bipartite multigraphs with n vertices per side and adjacency-array access. Hall-deficient and irregular graphs need a termination certificate. The hybrid's general-input guarantee is exactness. [Hopcroft–Karp](https://doi.org/10.1137/0202019) · [Goel–Kapralov–Khanna](https://arxiv.org/abs/0909.3346) |
| General cardinality and weight | Edmonds contracts odd cycles. Gabow batches shortest augmenting paths using tree set union. The independent weighted solver uses primal–dual search and solves components independently. A uniform-weight component uses Gabow. All retain original edge IDs, including the chosen representative of parallel edges. | The existing cardinality solver follows the 2026 canonical-path treatment. Integer weight scaling for weighted perfect matching is another research direction. Its bounds do not carry over to this event-driven solver. [Gabow](https://arxiv.org/abs/1703.03998) · [Mehlhorn–Nobahari](https://arxiv.org/abs/2603.22909) · [Duan–Pettie–Su](https://arxiv.org/abs/1411.1919) |
| Spanning forests and bottlenecks | Alongside Kruskal, the filtered MSF solver performs two Borůvka contractions, samples half of the remaining edges and excludes edges strictly heavier than the sampled forest path. It breaks ties by original ID and returns the same forest as Kruskal. Wilson's loop-erased walk samples a uniform spanning tree per connected component when the desired output is random. | Karger–Klein–Tarjan obtain expected linear time using a linear-time forest verifier. This implementation sorts the sampled forest for its path-maximum index and sorts its final output. Wilson uses uniform incident-edge choices, so parallel edges participate individually. The deterministic low-stretch forest instead grows bounded-radius balls in successive edge-length classes, retaining original edges as it contracts clusters. Its objective is average stretch. [Alon–Karp–Peleg–West](https://dwest.web.illinois.edu/pubs/kserver.pdf) [Karger–Klein–Tarjan](https://people.csail.mit.edu/karger/Papers/mst.pdf) · [Wilson](https://www.cs.cmu.edu/~15859n/RelatedWork/RandomTrees-Wilson.pdf) |

## Connectivity, reachability and routing

| Workload | Implementation and resource tradeoff |
| --- | --- |
| Static connectivity, dynamic connectivity | Weak and strong component labels answer pair queries in O(1) after O(V+E) construction. Union by size with path halving supports incremental connectivity. The offline algorithm with deletions uses edge-lifetime segments and rollback union–find. Rollback checkpoints are also public. |
| Static weighted connectivity | For queries asking whether every edge on some undirected path can have weight at most t, Kruskal merges form a binary forest. A lowest common ancestor gives the first connecting weight. An Euler tour and constant-time range minima support O(1) threshold queries after sorting. [Bender–Farach-Colton](https://ics.uci.edu/~eppstein/261/BenFar-LCA-00.pdf) |
| Large directed reachability | Both indexes contract SCCs. The GRAIL variant rejects impossible interval containments, accepts DFS-tree descendants, and verifies ambiguous cases by searching the condensed graph. At fixed dimension its storage and worst-case query work are linear. A chain index stores the earliest reachable member of each chain. It guarantees O(1) queries using Ck table entries for C components and k greedy chains. The caller can cap the table before allocation. Wide antichains favor the interval index. [GRAIL](https://vldb.org/pvldb/vol3/R24.pdf) · [Kritikakis–Tollis](https://doi.org/10.4230/LIPIcs.SEA.2023.2) |
| Traversal and grids | Push/pull BFS switches from outgoing arcs of frontier vertices to incoming arcs of undiscovered vertices on broad levels. The insertion-ordered BFS remains available. Grids retain implicit neighbors, A* and multi-source fields. A grid connectivity snapshot answers repeated obstacle-aware reachability queries in O(1). Four-way JPS uses horizontal-first pruning and vertical jumps to forced turns, with Manhattan A* and explicit path reconstruction. [Baum](https://arxiv.org/abs/2501.14816) [Beamer et al.](https://people.eecs.berkeley.edu/~krste/papers/beamer-sc2012.pdf) · [Harabor–Grastien](https://doi.org/10.1609/aaai.v25i1.7994) |
| Nonnegative and signed shortest paths | The radix implementation exploits monotone unsigned integer distances. Fibonacci-heap Dijkstra gives O(E+V log V) amortized time. The crate also supplies ALT for repeated point-to-point queries, DAG routing, minimax, Yen, Johnson, blocked Floyd–Warshall and signed solvers with witnesses. Recent directed SSSP results address the comparison-addition model for real weights. The crate's integer-queue results have a different computational model. [Fredman–Tarjan](https://www.cl.cam.ac.uk/teaching/1112/AlgorithII/1987-FredmanTar-fibonacci.pdf) · [Ahuja et al.](https://doi.org/10.1145/77600.77615) · [2026 directed SSSP](https://arxiv.org/abs/2602.07868) · [November 2026 preprint](https://arxiv.org/abs/2611.26453) · [Signed-path survey and implementation details](negative-shortest-paths.md) |
| Data structures and graph access | The immutable CSR graph shares stable IDs with attribute maps, views and result certificates. The public structures module includes indexed radix and Fibonacci queues, bounded-arity ordered trees, point-update segment trees, Fenwick frequencies and static range minima. Segment folds preserve operand order for noncommutative operations. The preferential-attachment generator uses the public Fenwick tree for inverse cumulative-frequency sampling. [Fenwick](https://doi.org/10.1002/spe.4380240306) |

## Structure, network analysis and generation

| Family | Implementations and literature |
| --- | --- |
| Planarity and isomorphism | Left–right testing constructs the rotation system. The dual API creates one dual edge per projected primal edge, including loops for bridges. For disconnected embeddings it identifies one exterior per component with a common exterior face. Boyer–Myrvold provides an alternative linear-time embedding and obstruction algorithm. VF2++ handles whole graphs and induced subgraphs. An AHU-style classifier now handles unordered rooted trees using sorted child classes. Its expected cost is O(V log V) with hash interning. Babai's quasipolynomial general-isomorphism bound applies to a different algorithm. [Boyer–Myrvold](https://doi.org/10.7155/jgaa.00091) · [VF2++](https://egres.elte.hu/www/tr-18-03.html) · [Rooted-tree isomorphism](https://arxiv.org/abs/2401.07636) · [Babai](https://arxiv.org/abs/1512.03547) |
| Centrality and clustering | The crate supplies PageRank, exact distance centralities and Brandes betweenness. Sampling k distinct uniform sources replaces V Brandes traversals with k and multiplies the sum by V/k. This is an unbiased estimate. Exact triangle counting and k-truss use the simple projection. For the mean local clustering coefficient, sample a uniform vertex and a random pair of its neighbors. Vertices with fewer than two neighbors contribute zero. [Brandes](https://snap.stanford.edu/class/cs224w-readings/brandes01centrality.pdf) · [Brandes–Pich](https://kim246.wwwdns.kim.uni-konstanz.de/publications/bp-celn-06.pdf) · [Schank–Wagner](https://www.jgaa.info/index.php/jgaa/article/view/paper108) |
| Communities | Weighted directed or undirected modularity optimization uses Louvain. The new undirected unweighted active-queue solver revisits neighbors after a label change. Keeping the existing label on ties guarantees termination since each change increases the number of agreeing edges. Both return heuristic partitions. The weighted undirected Leiden implementation performs one multilevel modularity pass with seeded node moves, randomized nondecreasing merges within coarse communities, and aggregation that retains coarse labels. If all admissible random choices stay put, one admissible merge ensures progress. If no merge is admissible, splitting the coarse partition by positive-edge connectivity terminates refinement. The returned groups are connected. No global optimality claim applies. [Louvain](https://arxiv.org/abs/0803.0476) · [Fast label propagation](https://doi.org/10.1038/s41598-023-29610-z) · [Leiden](https://arxiv.org/abs/1810.08473) |
| Random networks | Independent bipartite edges use geometric skips. A union of independent random perfect matchings produces a regular bipartite multigraph. For a uniform simple d-regular graph, shuffle labelled stubs and reject nonsimple pairings. Every simple labelled realization has the same number of pairings. Complementation covers high degrees, and the caller can bound rejected trials. Gao–Wormald switchings improve acceptance in broader degree regimes. Binomial random intersection graphs connect vertices sharing any sampled attribute. These join existing G(n,p), G(n,m), block, configuration, small-world, preferential attachment, geometric and lift models. [Batagelj–Brandes](https://doi.org/10.1103/PhysRevE.71.036113) · [Gao–Wormald](https://arxiv.org/abs/1511.01175) · [Random intersection graphs](https://www.cambridge.org/core/journals/combinatorics-probability-and-computing/article/abs/on-random-intersection-graphs-the-subgraph-problem/E652CFD84DE9A1AF53FD6D043931C6D6) |

## Additional exact solvers and certificates

- **Minimum-cost transshipment.** Capacity scaling saturates eligible negative-reduced-cost residual arcs at each threshold. Multi-source Dijkstra connects excess to deficit, updating node potentials by truncated shortest distances. At unit scale, zero imbalance and nonnegative residual reduced costs certify optimality. Minimum-mean-cycle cancellation instead starts with a feasible integral flow and pivots on a cheapest-mean residual cycle. Its Karp selector works per strongly connected component and replays exact-length walk distances in two passes to keep storage linear. Both support signed costs, parallel arcs and negative loops. [Edmonds and Karp](https://web.eecs.umich.edu/~pettie/matching/Edmonds-Karp-network-flow.pdf) · [Goldberg and Tarjan](https://doi.org/10.1145/76359.76368) · [Karp](https://www2.eecs.berkeley.edu/Pubs/TechRpts/1977/Archive/ERL-m-77-47.pdf)
- **Cycle ratios.** Static parametric search at ratio p/q tests for a negative cycle with lengths q·cost − p·length. Each improving cycle supplies the next rational threshold. This gives a small-graph exact oracle with ordered edge witnesses and checked arithmetic. The directed API includes positive optima. The undirected API traverses signed gradients in either orientation and returns a strictly improving cycle when one exists.
- **Fractional packing.** Each round routes a scaled demand vector on shortest paths under current edge prices. Price increases depend on the added congestion. Dividing the total allocation by its maximum congestion gives a feasible flow. Dividing the capacity-weighted sum of lengths by the demand-weighted sum of shortest-path lengths gives an upper bound on the attainable multiplier. The implementation uses these observed bounds for stopping in floating-point arithmetic. [Garg and Könemann](https://doi.org/10.1137/S0097539704446232)
- **Chordal graphs.** Maximum cardinality search and a grouped later-neighbor containment check recognize chordality in O(V+E). A perfect elimination order gives both a maximum clique and a proper coloring using the same number of colors. All three operate on the simple undirected projection. [Tarjan and Yannakakis](https://doi.org/10.1137/0213035)

The subpolynomial-update hierarchy and end-to-end bound for general deterministic almost-linear flow, integer weight-scaling perfect matching, Boyer–Myrvold embedding, Babai general isomorphism, Gao–Wormald regular sampling and the general directed SSSP bounds cited above remain literature references. The [signed-path survey](negative-shortest-paths.md) identifies the implemented components of its separate comparison.

## Measured reachability workloads

A release build on arm64 macOS tested 2,000 fixed vertex pairs on graphs with 100,000 vertices in four directed lanes. Occasional cross-lane arcs permit changes of lane. The second workload adds short reverse arcs to create SCCs. Each batch contains 1,007 reachable pairs. The harness compares every answer and times preprocessing separately. These are single-run elapsed times on deliberately narrow graphs.

| Graph | Arcs | Bidirectional BFS batch | Interval build | Interval batch | Chain build | Chain batch |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Lanes | 100,881 | 398.96 ms | 20.28 ms | 29.60 ms | 11.01 ms | 0.024 ms |
| Lanes with SCCs | 194,629 | 392.26 ms | 4.61 ms | 1.35 ms | 4.04 ms | 0.013 ms |

Both greedy covers used four chains. Reproduce with `cargo bench --locked --no-default-features --bench reachability`. The [weighted matching benchmark](../benches/weighted_matching.md) records the separate performance tradeoff for the replacement blossom solver.
